# 4.2 Cursor / Trae / Windsurf 放在哪里

这三类工具不需要过度展开，但需要知道它们在工作流中的位置：它们更像编辑器增强，而不是整套任务治理系统。

## Cursor

Cursor 的价值主要在编辑器体验：

- 编辑器体验完整。
- 代码补全和局部修改好用。
- 对传统 IDE 用户迁移成本低。
- 适合人在编辑器中主导的开发方式。

什么时候用：

- 快速补全。
- 阅读代码。
- 局部重写。
- UI 小改。
- 人想持续掌控每个编辑动作。

什么时候不作为主线：

- 长任务。
- 多 Agent。
- 复杂验证。
- 需要任务状态和规范层。

## Trae

Trae 的吸引力通常在于门槛低：

- 低门槛。
- 成本和模型可用性。
- 对新用户友好的 IDE 形态。

适合：

- 想用 AI IDE 快速开始。
- 不想先配置复杂 CLI。
- 局部功能修改。

不适合：

- 作为本手册的主线工具。
- 替代完整 harness。

## Windsurf

Windsurf 的价值在于编辑器内的连续操作体验：

- 多步骤编辑器内工作流。
- Cascade 类体验。
- 对大型代码库有一定上下文辅助。

适合：

- 想留在 IDE 中做较连续的任务。
- 需要比传统补全更主动的编辑体验。

局限：

- 长任务治理仍需要额外规范。
- 和 TUI Agent 的任务系统、worktree、skills/harness 不是同一类重点。

## 结论

```text
Cursor / Trae / Windsurf:
  适合作为编辑器增强。

Claude Code / Codex / OpenCode:
  更适合作为任务执行和工作流主线。
```

本手册不否定编辑器工具。它们有实际价值，只是不适合单独承担长期 AI 开发系统的核心层。
