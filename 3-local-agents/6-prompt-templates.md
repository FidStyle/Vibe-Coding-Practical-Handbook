# 3.6 本地 Agent 任务模板

下面这些模板面向本地 Agent 的第一次稳定执行，可以直接用于 `Claude Code`、`Codex` 或 `OpenCode`。先按模板使用，稳定后再按工具差异微调 agent、模型、权限和命令。

如果你已经进入日常工作流，需要跨阶段的只读分析、diff 审查、文档同步和收尾提示，直接读 [8.5 跨阶段提示词库](../8-best-practices/5-prompt-library.md)。

## 模板 1：只读分析

```text
你现在在一个真实代码仓库里工作。

请先只读分析，不要修改文件。

目标：
<写清楚要完成什么>

请完成：
1. 阅读相关文件和现有类似实现。
2. 找出需要修改的文件范围。
3. 总结现有模式。
4. 列出风险和不确定点。
5. 给出验证命令。

等我确认后再开始修改。
```

## 模板 2：功能实现

```text
目标：
<功能目标>

上下文入口：
- <路径 1>
- <路径 2>

约束：
- 不引入新依赖。
- 不修改公开 API。
- 不重构无关代码。

完成标准：
- <验收 1>
- <验收 2>
- 相关测试通过。

请先给计划，确认后再实现。
```

## 模板 3：Bug 修复

```text
问题：
<现象>

复现步骤：
1. <步骤>
2. <步骤>

错误输出：
<粘贴日志或 stack trace>

要求：
1. 先定位可能根因，不要直接改。
2. 找到相关代码和测试。
3. 给出最小修复计划。
4. 修复后补回归测试。
5. 跑相关验证。
```

## 模板 4：重构

```text
目标：
重构 <模块>，解决 <重复/复杂/性能/可维护性问题>。

边界：
- 不改变外部行为。
- 不改变公开接口。
- 不改无关文件。

要求：
1. 先分析当前结构。
2. 列出重构步骤。
3. 每步保持可运行。
4. 使用现有测试证明行为不变。
5. 如果缺测试，先补 characterization test。
```

## 模板 5：代码审查

```text
请审查当前 git diff。

重点：
1. 是否有行为回归。
2. 是否有安全风险。
3. 是否缺测试。
4. 是否违反项目约定。
5. 是否有无关改动。

请只列可验证的风险，不要泛泛建议。
每条问题要给出文件、原因和建议修复方式。
```

## 模板 6：沉淀规范

```text
请基于这次任务复盘：
1. 哪些问题是项目规则缺失导致的？
2. 哪些规则应该写入 AGENTS.md / CLAUDE.md / agent config？
3. 哪些流程适合做成 skill？
4. 哪些内容只是一次性经验，不需要固化？

请给出最小规则补丁，不要写长篇教程。
```

## 模板 7：多模型对照

```text
请不要修改文件。现在只做第二意见审查。

输入：
- 当前任务目标：<目标>
- 当前 diff 或计划：<贴摘要或路径>

请重点检查：
1. 是否有更小的实现路径。
2. 是否遗漏边界情况。
3. 是否需要测试或文档。
4. 是否存在安全、性能或兼容性风险。
5. 哪些建议是必须修，哪些只是可选优化。

不要泛泛建议。每条建议必须能落到文件、行为或验证命令。
```
